# Orchestration architecture documents

This path is a stable index. It intentionally contains no current tool count,
Store protocol number, action-contract version, or module-size snapshot.

Use these documents according to purpose:

- [Current architecture and health budget](./current-architecture.md) is the
  only authoritative description of the source tree and public surface now.
- [Issue #126 orchestration refactor history](./orchestration-refactor-history.md)
  is an immutable chronological record of the v0.12 refactor baseline, phase
  reports, and later issue addenda. Numbers such as 14 or 16 tools, Watch v2,
  and writer protocol 6 describe their explicitly dated historical snapshot;
  they are not current product documentation.
- [Issue #126 final report](./issue-126-final-report.md) records that refactor's
  closeout evidence.
- [Interactive terminal response](./interactive-terminal-response.md) describes
  the dedicated questionnaire-response architecture.

For operator workflows and the current semantic-tool surface, use the
[operator guide](../operator-guide.md) and the canonical packaged Skill.
